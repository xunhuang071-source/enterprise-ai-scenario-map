# 模板使用说明

## 确认表模板（确认表模板.md）

「应用场景确认表」的完整规格：工作簿结构、编制说明全文、字段口径、下拉规则。模板不预置任何客户信息与年份。

仓库不附带二进制 Excel 母版。按规格在 Excel 或 WPS 中几分钟即可自制；也可以联系序创信获取母版（联系方式见仓库根目录 README）。

## 生成项目副本

已有 Excel 母版时，不要直接改母版。用脚本生成项目副本，只改年度相关字段，其余版式逐字节保留：

```bash
python3 scripts/prepare_workbook.py --template 你的母版.xlsx --output 项目确认表.xlsx --years 2029 2030 2031
```

- 三个年度必须不同且递增；脚本拒绝覆盖已存在的输出文件。
- 生成后复核客户口径、年度与下拉选项，再发给部门确认。

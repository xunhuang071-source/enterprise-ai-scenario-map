# 行业实践案例模板

记录可借鉴机制，不拼凑客户收益。

## 字段

- 实施单位、行业、业务范围、应用状态（概念／试点／已投运）。
- 具体任务、输入、AI 动作、输出、人员职责、使用范围。
- 公开披露的技术路径与供应商（仅在来源支持时记录，不猜架构和组件）。
- 实施效果原文、指标定义、样本和时间；数字来自谁，是否第三方验证。
- 标题、发布主体、日期、URL／材料定位、查阅日期；多个转载追到原始出处。
- 可借鉴条件、与本客户差异、待验证问题、对应大场景／用例。

无效果数字可保留真实机制，不要求每例强行量化。案例数按相关性和证据充分度，不固定配额。
历史实绩可带来源引用，不转换成客户收益承诺；官方宣传也需保留披露口径，不能凭空补原报告未写的技术栈。
纯概念作线索，不写成已投运；趋势设计可提出新用例，不必须先找一个同行才能构思。
